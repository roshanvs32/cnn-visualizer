# 🧠 NeuroVision

A PyTorch project where I'm learning how Convolutional Neural Networks (CNNs) work by building one from scratch.

## 🚀 Features

- CNN built using PyTorch
- Trained on the MNIST dataset
- Predicts handwritten digits (0–9)
- Save and load trained models
- Test with custom handwritten images

## 🛠️ Tech Stack

- Python
- PyTorch
- TorchVision
- PIL

## 🎯 Roadmap

- ✅ Build CNN
- ✅ Train on MNIST
- ✅ Predict custom digits
- ⏳ Improve model architecture
- ⏳ Visualize neural network layers
- ⏳ Build an interactive CNN visualizer

## 📚 Dataset

- MNIST Handwritten Digits Dataset
